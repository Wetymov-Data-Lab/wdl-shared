# @wdl/wdl-shared

Общая Python-библиотека проектов WDL.

<details>
<summary><strong>Installation</strong></summary>

```bash
uv add "wdl-shared @ git+https://github.com/Wetymov-Data-Lab/wdl-shared.git@main"
```

</details>

---

<details>
<summary><strong>Project commands</strong></summary>

| Команда          | Назначение                             |
|------------------|----------------------------------------|
| `make sync`      | Установить зависимости для разработки |
| `make lint`      | Проверить код Ruff                     |
| `make typecheck` | Проверить типы mypy                    |
| `make test`      | Запустить тесты                        |
| `make check`     | Запустить все проверки                 |

</details>
